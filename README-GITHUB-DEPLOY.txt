RAGAS FRONTEND - GITHUB PAGES
=============================
Upload ALL files in this folder to the root of the RAGAS GitHub Pages site.
Keep .nojekyll.

The frontend already detects github.io and calls:
https://vege.mdmsportal.uk

Do not put server.js, data.sqlite3, .env, backups, node_modules, secrets, or Cloudflare token files in GitHub Pages.
